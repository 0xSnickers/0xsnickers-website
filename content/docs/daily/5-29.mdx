待解决问题：
> 2核 2GiB 的服务器跑 Next.js + Fumadocs MDX 的 build 非常容易卡死或 OOM（内存耗尽）
> 尤其是 npm run build 那一步
> Fumadocs 处理 MDX 文件时内存峰值经常会冲到 4GB+，服务器根本扛不住

解决方案：
- 将 npm ci 和 npm run build 交给 github action 执行，通过 standalone 模式打包
- 将 `.next/standalone 和 .next/static` 压缩打包成 release.tar.gz，通过 SSH 上传给云服务器
- 云服务器只负责解压和运行项目

流程
```text
GitHub Actions
  npm ci
  npm run build
  package .next/standalone, .next/static, and public into release.tar.gz
  upload release.tar.gz to the server

Server
  extract release.tar.gz
  switch the current release directory
  run server.js with PM2
```
