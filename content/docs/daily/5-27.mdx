## 通用结构原则

- `components/common`：无业务耦合的基础组件。
- `components/layout`：页面布局、导航、壳组件。
- `components/feature`：业务功能组件。
- `services/api`：HTTP 客户端和接口封装。
- `config`：环境变量和应用配置。
- `types`：全局类型、API 类型、业务实体类型。
- `utils`：纯函数工具。
- `assets`：图片、图标、字体等静态资源，按模板能力选择是否启用。
- `providers`：应用级或功能级 Provider，用于承接主题、鉴权、页面上下文等共享依赖。
- `store` / `stores`：跨页面共享状态。
- `hooks` / `composables`：框架对应的逻辑复用入口。
- `src/test`：测试环境 setup、测试工具封装。
- `tests`：跨模块单元测试、集成测试、E2E 测试。

## Provider 使用原则

React / Next.js 项目需要有 Provider 意识，用于解决页面或功能模块中的 prop drilling。

- 2 层以内的简单参数传递继续使用 props。
- 3 层以上传递、兄弟组件共享上下文、页面级筛选条件、当前业务实体等场景优先考虑功能级 Provider。
- 跨页面共享、持久化、登录态等状态使用 `store`。
- 接口缓存和服务端数据优先交给 TanStack Query 或框架数据获取能力，不要全部放入 Provider。
- Provider 不应变成万能全局状态容器，作用域越小越好。

## HTTP 请求规范

所有前端模板统一使用 Axios 调用 HTTP 接口，并通过 `services/api/httpClient` 暴露通用客户端。

- 页面和组件不得直接调用 `fetch` 或散落创建 Axios 实例。
- 业务接口统一放在 `services/api/*Api.ts`。
- `baseURL` 统一从 `config/env` 读取。
- 通用拦截器、超时、错误处理统一在 `httpClient` 中维护。

## 质量工具

模板默认提供轻量质量工具：

- ESLint：基础代码问题和框架规则检查。
- Prettier：统一格式化，减少风格争论。
- Vitest / Jest：默认单元测试入口。

常用命令：

```bash
npm run lint
npm run format
npm run typecheck
npm run test
```

## 使用方式

```bash
cp -R frontend/reactjs-template my-new-project
cd my-new-project
npm install
cp .env.example .env
npm run dev
```

复制后必须更新：

- `package.json` 中的项目名。
- `README.md` 中的项目说明。
- `.env.example` 中的接口地址和运行配置。
- `src/config/env.*` 中的环境变量校验。
- `services/api/*Api.ts` 中的业务接口。

## Next.js 模板项目结构

```text
nextjs-template/
├── src/
│   ├── app/                           # App Router 路由、布局、错误边界
│   │   ├── page.tsx                   # 根路径入口，重定向到默认语言
│   │   ├── layout.tsx                 # 根布局
│   │   └── [locale]/                  # 多语言业务路由，中文 /zh，英文 /en
│   ├── components/
│   │   ├── common/                    # 基础组件和通用交互入口
│   │   ├── layout/                    # 应用壳、页面布局
│   │   └── feature/                   # 业务功能组件
│   ├── providers/                     # 应用级或功能级 Provider
│   ├── services/api/                  # Axios 客户端、API 模块、错误模型、Token 工具
│   ├── store/                         # Zustand 跨页面客户端状态
│   ├── hooks/                         # React Hook 和业务逻辑复用
│   ├── i18n/                          # next-intl 配置、路由、语言包
│   ├── theme/                         # 主题变量和运行时切换
│   ├── config/                        # 环境变量解析和应用配置
│   ├── types/                         # API 类型和业务实体类型
│   ├── utils/                         # 纯函数工具
│   ├── styles/                        # 全局样式
│   ├── test/                          # Vitest / Testing Library setup
│   └── proxy.ts                       # next-intl 请求中间件
├── tests/
│   ├── unit/                          # 跨模块单元测试
│   ├── integration/                   # 集成测试
│   └── e2e/                           # 端到端测试
├── public/                            # 静态资源
├── next.config.mjs
├── vitest.config.ts
├── eslint.config.mjs
├── package.json
├── README.md
├── GUIDE.md
├── TEST.md
├── MERMAID.md
├── AGENTS.md
└── CLAUDE.md
```
