LP 是 Liquidity Provider，也就是流动性提供者。你把两种资产放进 AMM 池子里，换取 LP Token，LP Token 代表你对池子的份额。

## 场景

假设有一个刚创建的 `$SNK / ETH` 池子。

你是第一个添加流动性的人：

```text
100 SNK + 1 ETH
```

如果当时价格是：

```text
1 ETH = 100 SNK
```

那你就等于设置了池子的初始价格。

## LP Token 是什么

当你添加流动性后，池子会铸造 LP Token 给你。

如果你是第一个添加流动性的人，那么你拥有池子 100% 的 LP Token，也就拥有池子 100% 的份额。

LP Token 代表：

- 你在池子里的资产份额。
- 你可以按份额取回池子资产。
- 你可以按份额获得交易手续费。

## 无常损失是什么

无常损失是指：提供流动性后，因为价格变化，你最终拿回的资产价值可能低于单纯持有这两种资产。

简单说：

```text
LP 收益 = 手续费收入 - 无常损失
```

如果价格长期横盘，并且交易量很高，LP 通常更舒服，因为无常损失小，手续费持续累积。

如果价格大涨或大跌，无常损失会变大。

## 例子

你初始放入：

```text
100 SNK + 1 ETH
```

如果 SNK 价格上涨，套利者会不断从池子里买走 SNK，池子里的 SNK 变少，ETH 变多。

你退出时，拿回的可能不再是：

```text
100 SNK + 1 ETH
```

而是类似：

```text
更少的 SNK + 更多的 ETH
```

如果和“什么都不做，直接持有 100 SNK + 1 ETH”相比，少赚的部分就是无常损失。

## 注意事项

- 第一个 LP 可以设置初始价格，权力很大，风险也很大。
- 横盘不一定赚钱，关键还要看交易量。
- 手续费必须覆盖无常损失，LP 才有实际收益。
- Meme 币价格波动大，无常损失风险通常更高。

## 总结

LP Token 代表你对流动性池的份额。无常损失来自价格偏离初始比例，价格波动越大风险越高。LP 是否赚钱，核心看手续费收入能不能覆盖无常损失。
