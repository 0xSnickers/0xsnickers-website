## 文章核心内容

参数化查询把 SQL 语句与外部输入分开传递，适合所有需要接收用户参数的后端接口。驱动按参数处理输入，减少 SQL 注入风险。

## 使用方式

先确认数据库驱动支持的占位符格式。MySQL 常用问号，PostgreSQL 常用 $1、$2；通过驱动参数列表传值。

## 怎么实现

### 1. 固定 SQL 结构

下面示例使用 node-postgres 已创建的连接池：

```ts
const result = await pool.query(
  "SELECT id, name FROM users WHERE email = $1 LIMIT 1",
  [email],
);
```

### 2. 校验动态排序

表名、列名和排序方向通常不能作为普通值参数绑定。使用固定映射或白名单选择 SQL 片段，再单独绑定查询值。

## 常见问题

### ORM 是否能自动保证安全

ORM 的普通查询通常会绑定参数；拼接原始 SQL 时仍然需要检查输入处理。不要把用户输入直接拼进 SQL 字符串。

### 参数化查询能替代输入校验吗

参数绑定负责安全地传递查询值，输入校验负责检查类型、长度和业务规则。接口应同时保留这两层处理。
