这里记录 Node.js 后端开发中常用的基础知识、接口设计、数据库访问和 Express 开发笔记。

内容尽量保持简洁，重点说明：它解决什么问题、怎么使用、使用时要注意什么。

## 内容分类

- [Node.js](/docs/backend/nodejs)：运行时、模块系统、异步模型、错误处理和环境变量。
- [Express](/docs/backend/express)：路由、中间件、请求响应、错误处理和接口组织。
- [Prisma](/docs/backend/prisma)：数据库模型、Prisma Client、迁移和常用查询。
