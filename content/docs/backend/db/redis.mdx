## 文章核心内容

Redis 是以内存访问为主的数据存储，适合缓存、计数器、排行榜和临时状态。它提供字符串、哈希、集合和有序集合等数据结构，后端可以直接围绕这些结构实现功能。

- 缓存设置过期时间。
- 计数使用原子命令。
- 根据可恢复要求选择持久化和备份策略。

## 使用方式

先确认 Redis 已启动，并配置认证和网络访问限制。在本机使用客户端连接：

```bash
redis-cli -h 127.0.0.1 -p 6379
```

以下命令在 redis-cli 内执行；业务连接使用 Redis 客户端和连接池。

## 怎么实现

### 1. 写入带过期时间的缓存

```text
SET user:1:name Alice EX 300
GET user:1:name
TTL user:1:name
DEL user:1:name
```

缓存未命中时查询主数据库，再回填缓存。更新主数据库后删除对应缓存，并为热点 key 的过期时间加入适量随机偏移。

### 2. 使用合适的数据结构

```text
HSET user:1 name Alice role reader
HGETALL user:1
INCR article:1:views
ZADD leaderboard 100 alice 80 bob
ZREVRANGE leaderboard 0 9 WITHSCORES
```

INCR 单条命令是原子的。需要让计数和首次设置过期时间一起完成时，可以用 Lua 脚本把操作组合起来。

### 3. 控制内存并规划持久化

设置合理的 maxmemory 和淘汰策略。RDB 保存时间点快照，AOF 记录写操作；恢复能力取决于配置和落盘时机。

> 缓存可能过期、被淘汰或因故障丢失，关键业务数据应有明确的可靠存储来源。

## 常见问题

### 缓存穿透与缓存击穿

不存在的数据反复查询会穿透缓存，可短暂缓存空值；热点 key 失效时大量请求同时回源，可用请求合并或互斥重建控制并发。

### 删除大 key 时出现延迟

大对象操作会占用处理时间。拆分大 key，遍历使用 SCAN，并在适用时用 UNLINK 异步释放内存。
