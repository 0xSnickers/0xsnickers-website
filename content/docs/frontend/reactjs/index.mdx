---
title: React.memo 和 useCallback
description: 💡 React.memo + useCallback = 最佳拍档
---

> - `React.memo`：是一个 高阶组件（HOC） ，它的作用是： "如果 props 没变，就不要重新渲染这个组件；
> - `useCallback`：缓存一个函数，防止它在组件每次重新渲染时都被重新创建；


普通组件（没有 memo）
每次父组件重新渲染，子组件 也会跟着重新渲染 ，不管 props 有没有变：
```js
function MyButton({ onClick }) {
  console.log('MyButton 渲染了');
  return <button onClick={onClick}>点击</button>;
}
```
用了 React.memo 的组件
只有当 props 真正发生变化 时，才会重新渲染
```js
const MyButton = memo(({ onClick }) => {
  console.log('MyButton 渲染了');
  return <button onClick={onClick}>点击</button>;
});
```

Demo
结果 ：点击 Count， MyButton 不会 重新渲染（因为 handleClick 引用没变）

```js
import { useState, useCallback, memo } from 'react';

// ✅ memo 组件
const MyButton = memo(({ onClick }) => {
  console.log('MyButton 渲染了');
  return <button onClick={onClick}>点击</button>;
});

function Parent() {
  const [count, setCount] = useState(0);

  // ✅ useCallback 缓存函数引用！
  const handleClick = useCallback(() => {
    console.log('clicked');
  }, []);

  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>Count: {count}</button>
      <MyButton onClick={handleClick} />
    </div>
  );
}
```
