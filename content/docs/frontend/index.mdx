这里记录前端开发中常用的框架、样式生态和组件设计笔记。

内容尽量保持简洁，重点说明：它解决什么问题、怎么使用、使用时要注意什么。

## 内容分类

- [ReactJS](/docs/frontend/reactjs)：组件、状态、Hooks、Provider、性能优化和 React 实现原理。
- [Next.js](/docs/frontend/nextjs)：App Router、Server Component、Client Component、渲染模式、缓存和部署。
- [Vue 3](/docs/frontend/vue)：`ref`、`reactive`、`computed`、`watch`、组件通信、Pinia 和 Vue Router。
- [CSS](/docs/frontend/css)：Tailwind CSS、shadcn/ui、Radix UI 等样式和 UI 生态。
