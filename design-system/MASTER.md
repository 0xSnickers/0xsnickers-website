# Design System: 0xSnickers - Vibe Coder

## Pattern
- **Name:** Portfolio Journey
- **Conversion Focus:** Immersive project discovery. High engagement. Keep navigation visible.
- **CTA Placement:** Floating Sticky CTA or End of Project Track
- **Color Strategy:** Continuous palette transition. Chapter colors. Progress bar #000000.
- **Sections:** 1. Intro (Vertical), 2. Projects Journey, 3. Skills Reveal, 4. Contact Footer

## Style
- **Name:** Aurora UI + Vibe Coding
- **Keywords:** Vibrant gradients, smooth blend, Northern Lights effect, mesh gradient, luminous, atmospheric, abstract, playful, creative, developer portfolio
- **Best For:** Creative developers, portfolio sites, coding projects, Web3 projects, creative tech
- **Performance:** ⚠ Good
- **Accessibility:** ⚠ Text contrast

## Typography
- **Heading:** Baloo 2
- **Body:** Comic Neue
- **Mood:** playful, friendly, colorful, creative, developer-focused
- **Best For:** Creative portfolios, developer sites, personal branding
- **Google Fonts:** https://fonts.google.com/share?selection.family=Baloo+2:wght@400;500;600;700|Comic+Neue:wght@300;400;700

## Key Effects
- Mesh gradients, multi-color blend
- Aurora/Northern Lights effect
- Large flowing CSS/SVG gradients
- Subtle 8-12s animations
- Depth via color layering
- Smooth color morphing
- Iridescent overlays
- Holographic shimmer
- Code/dev aesthetics

## Avoid (Anti-patterns)
- Generic corporate templates
- Complex booking forms
- Emojis as icons (use SVG: Heroicons/Lucide)
- Boring developer portfolios
